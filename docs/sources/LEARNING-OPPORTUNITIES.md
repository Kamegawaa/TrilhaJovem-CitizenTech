# Initial learning opportunity directory

This MVP directory links to official learning platforms. It does not scrape course listings or claim real-time availability.

- Escola Virtual Gov: https://www.escolavirtual.gov.br/
- CIEE Saber Virtual: https://portal.ciee.org.br/quero-me-preparar/saber-virtual/
- AVAMEC / MEC: https://avamec.mec.gov.br/
- Fundação Bradesco Escola Virtual: https://www.ev.org.br/
- SENAI Educação a Distância: https://www.portaldaindustria.com.br/senai/canais/educacao-a-distancia/

Availability, eligibility, certification, costs and enrollment conditions must be confirmed on each provider's official website. Future integration should use documented public APIs or feeds where available; do not scrape undocumented endpoints.
